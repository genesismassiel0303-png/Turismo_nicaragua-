Preguntas de análisis

  1. ¿Cuál es la diferencia entre type="text" y type="email"?

    Text permite escribir cualquier texto y email permite ingresar una dirección de correo electrónico.

  2. ¿Para qué sirve el atributo name?

    Sirve para identificar cada campo del formulario al enviar los datos.

  3. ¿Qué diferencia hay entre radio y checkbox?

    Radio permite seleccionar una opción y checkbox permite seleccionar varias.

  4. ¿Qué hace el atributo required?

    Hace que un campo sea obligatorio antes de enviar el formulario.

  5. ¿Se pueden guardar datos directamente en una base de datos usando solo HTML?

    No. Se necesita un lenguaje de programación del lado del servidor y una base de datos.
